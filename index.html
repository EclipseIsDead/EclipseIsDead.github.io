Engineering Notes

Types are infrastructure

In a large product, schemas are not just correctness tools. They become APIs, SDKs, runtime metadata, form renderers, validation layers, permissions, and migration boundaries. 

YAML schema
  -> parser / generator
  -> Python + TypeScript + OpenAPI + SDK
  -> runtime type information
  -> dynamic forms, pickers, validation, docs, and tools
Recovery paths matter more than happy paths

Event-driven systems look straightforward until pods die, consumers get stuck, messages are replayed, or state needs to be reconstructed after restart. Good infrastructure makes recovery boring. 

event -> queue -> control plane -> worker
  ^          |           |
  |          v           v
  +---- ack state   lifecycle/status reconciliation
Developer experience compounds

A repeated workflow does not need to look important to be worth optimizing. Backend HMR, Git performance, and fast local loops create leverage because every engineer pays that cost every day.

AI-assisted engineering needs boundaries

AI tooling is useful for parallelizing boilerplate migrations and frontend iteration. Human judgment should own schema design, security models, parser/cache correctness, and product constraints.
